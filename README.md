# lectureswtimecodes

Phone app that turns a lecture into a list of topics. Tap a topic and the player jumps there.

Open the folder in Android Studio and run it on a phone or emulator.

The three lectures already in the list are sample data. Record saves an audio file from the microphone. Open file copies the chosen audio into the app and plays it. Lectures you add are saved on the phone. Speech-to-text is not in yet.

# lectureswtimecodes

Phone app that turns a lecture into a list of topics. Tap a topic and the player jumps there.

Open the folder in Android Studio and run it on a phone or emulator.

The three lectures already in the list are sample data. Open file plays an audio file from the phone. Lectures you add are saved on the phone. Record counts time and does not save sound yet. Speech-to-text is not in yet.
